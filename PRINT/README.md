# Комплект для друку та макетування

- [Шаблон центральної панелі A4, PDF, масштаб 1:1](01-front-panel-template.pdf)
- [Вихідний векторний шаблон](01-front-panel-template.svg)
- [Параметрична модель панелі та притискача LCD](02-front-panel.scad)
- [Інструкція складання, HTML](03-instruktsiia-zbirka-uk.html) — відкрийте у браузері й надрукуйте на A4.
- [Інструкція складання, Markdown](03-instruktsiia-zbirka-uk.md) — редагований текст.

Шаблон і 3D-модель описують **центральну смугу 50×190 мм**, а не всю верхню кришку. Це попереднє припущення для корпусу з цільовими габаритами 240×190 мм. Перед різанням або друком перевірте чисту ширину, габарити корпусу, реальний дисплей, USB-модулі, перемикачі, LED і кріплення.

PDF шаблону друкуйте в масштабі 100%, без «підігнати до сторінки». Контрольний квадрат має бути 20×20 мм. Отвори тумблерів/LED і два USB-вікна задані умовно та мають бути виміряні за отриманими деталями. Перемикачі на панелі — лише логічні; вони не комутують струм батарей.

Файл SCAD можна відкрити в OpenSCAD і експортувати в STL через Render (F6 → Export as STL). Панель і притискач LCD експортуються окремо параметром `part`.

Батарейну збірку, BMS, запобіжники та силові з'єднання монтувати лише після перевірки паспортів, розрахунку захисту та стендових випробувань. Інструкція не містить процедури точкового зварювання чи припущень про контакти конкретної BMS.
