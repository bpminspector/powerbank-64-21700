# Power Bank 64 × 21700 для DJ-оборудования

Проект модульного аккумуляторного источника с двумя съёмными батареями 4S8P, выходами 12 V и 24 V, USB и мониторингом на ESP32-S3. Добавлен исходный каркас прошивки ESP-IDF для дисплея GC9107, измерений и ESP-NOW; силовая схема, сборка прошивки и прототип ещё не прошли проверку.

## Открытое решение

Для выхода 24 V нужно выбрать один согласованный номинал: 2,5 A = 60 W либо около 3,34 A = 80 W. Модели силовых модулей, точный экран, параметры USB и реальные нагрузки DJ-оборудования также требуют подтверждения.
