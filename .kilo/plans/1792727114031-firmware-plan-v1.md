# Firmware Plan — ESP32-S3 N8R2 DJ Power Bank

## Target hardware
- ESP32-S3 N8R2 (dual core, 240 MHz, 16 MB flash, 8 MB PSRAM)
- 2 battery blocks, 32x CMINR21700F2E 21700 (3.6V / 5000mAh) each, 4S8P
- GC9107 128x128 IPS TFT display (per Final_Layout_SidePacks.md)
- 3 touch buttons (left / OK / right)
- QIUWU INA226 current monitor
- Baseus charger (2x USB-A + 2x USB-C) as external charging source
- 300W 20A step-down module (6-40V in, 1.2-36V out) for the 24V output

## Confirmed requirements
- 1x 24V 2.5A 80W output
- 3x 12V 2A 24W outputs
- many USB ports
- Display showing state of charge, current draw, current intake
- Auto-switch to second block if first is depleted
- Charge via USB or direct block connection


## Open decision (blocking, affects ADC ranges and INA calibration)
Bus topology: parallel (~15V) or series (~30V).
Recommendation: SERIES, because the owned 300W module is step-down only and needs >=24V input to produce the 24V output, which is the highest-power DC load.
Risk to confirm: series peaks at 33.6V; check that the owned USB fast-charge modules accept that input voltage.

## Firmware responsibilities
1. Read INA226 over I2C: bus voltage, current, power.
2. Read block voltages via ADC (per-block sense).
3. Drive output enable lines (12V group, 24V, USB group) through relays/MOSFETs.
4. Manage block switch-over: monitor both blocks, disable depleted one, enable the other.
5. Render GC9107 display: SoC %, V, A, W, active outputs.
6. Handle 3 touch buttons: mode switch, output toggles, brightness.
7. Handle charging input: detect external charger, enable charge path, CC/CV profile to 16.8V.
